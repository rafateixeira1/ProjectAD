# ProjectAD

## Download do Dataset (CSV)

Devido ao tamanho do ficheiro, o dataset não está neste repositório. Para obter o ficheiro .csv, por favor, siga estes passos:

1. Aceda a: [Global Terrorism Database (Kaggle)](https://www.kaggle.com/datasets/START-UMD/gtd)
2. Faça login (ou crie uma conta) no Kaggle, se necessário.
3. Clique em "Download" para obter o ficheiro `globalterrorismdb_*.csv`.
4. Coloque o ficheiro CSV na pasta do seu projeto local, conforme necessário para executar os notebooks/scripts.

⚠️ Nota: O Kaggle pode pedir aceitação dos termos de utilização antes do download.
